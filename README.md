# 问卷云 · 星海回声

**可运行的第一版：React + FastAPI + SQLite。** 填写者打开链接或扫描二维码即可匿名回答，不需要 ChatGPT 账号；管理员用本应用的账号密码登录后台查看词云。

这是 GitHub 自建部署版本。此前的 Sites 演示仍是独立站点，两者不共享数据库或登录账号。

## Windows 快速测试

1. 安装 **Python 3.11 或更新版本**、**Node.js 22 LTS**。安装时将程序加入 PATH。
2. 下载此仓库 ZIP，**完整解压**到可写文件夹（不要在 ZIP 内直接运行）。
3. 双击根目录 **`start.cmd`**。
4. 首次启动会安装依赖、构建前端、生成本机密钥、初始化 SQLite，并要求设置管理员密码（至少 12 字符；输入密码时窗口不会显示字符）。默认账号为 `admin`。
5. 打开回答页 **http://localhost:8000**，后台为 **http://localhost:8000/admin**。

首次运行需要联网下载依赖。后续启动会检查文件变化，未修改的依赖与前端无需重新安装、构建。初始化不会覆盖已有管理员、问题或回答。保持命令行窗口打开，按 Ctrl+C 停止。

首次初始化带有一条可修改使用方式的示例问题：“如果用一个词描述你期待的未来，会是什么？”更换题目请在后台新建轮次并开启；创建后默认暂停。

macOS / Linux：准备同样的依赖，在根目录运行 `python3 scripts/start.py`。

## 启动窗口闪退或启动失败

新版 `start.cmd` 会在独立的命令解释器中运行，程序退出后窗口仍保持打开，并显示退出码。启动入口使用 ASCII 内容与 Windows 换行，避免批处理中文编码影响解析；Python 的提示仍显示中文。

如果旧版本双击后闪退，在项目文件夹的资源管理器地址栏输入 `cmd` 并回车，再执行：

```bat
start.cmd
```

也可直接执行 `py -3 -u scripts\start.py`；没有 `py` 时执行 `python -u scripts\start.py`。这样可以保留实际错误信息。请先确认已经完整解压 ZIP。

Python 启动流程报错时，会将异常写入项目根目录 `startup-error.log`（不记录环境变量或管理员交互密码）。可以发送窗口最后几行或这个日志以继续排查。运行环境缺失或批处理本身报错时，可能没有该日志，仍以窗口输出为准。

## 手机 / 多设备测试

- 电脑和手机连接同一网络；电脑保持服务运行。
- 用 `ipconfig` 查看电脑局域网 IPv4，例如 `192.168.1.20`。
- 停止程序，在根目录 `.env` 中将 `PUBLIC_ORIGIN` 改为 `http://192.168.1.20:8000`，然后重启。
- **电脑和手机都使用这个地址访问**，不要一端用 localhost、另一端用 IP。写请求会校验配置的来源。
- 按 Windows 防火墙提示允许专用网络访问；不要将开发端口直接转发到公网。
- 后台“下载二维码”生成该地址的 SVG。默认 localhost 二维码只适合当前电脑，不可给手机扫码。

填写不要求账号。默认同一轮每个浏览器接受一条回答；同设备换浏览器、清除 Cookie 或换设备可以再次提交，因此这里统计的是回答数，不是实名参与人数。

## 已实现功能

| 功能 | 行为 |
|---|---|
| 单问题页面 | 深空背景、光环、中文输入、移动布局、失败保留输入与成功反馈 |
| 回答保存 | 100 字上限、共享 SQLite、幂等请求、浏览器去重、提交限流 |
| 管理登录 | Argon2 密码哈希、HttpOnly Cookie、8 小时会话、CSRF 与来源校验 |
| 问题轮次 | 创建、开启、暂停；最多开放一轮，历史回答分开统计 |
| 词云与排名 | d3-cloud 碰撞布局、前 80 词词云、完整排名分页、每 5 秒增量检查 |
| 原文追溯 | 点击词语查看贡献该词的有效原文，回答分页、排除 / 恢复 |
| 分词规则 | jieba、停用词、短语、显式同义词、后台分批重算及原子切换 |
| 分享 | 回答页链接、后台下载二维码，不调用外部二维码服务 |
| 运维 | 版本化迁移、SQLite 一致性备份、校验、恢复前快照、配置导入导出 |
| 部署 | 多阶段 Dockerfile、单进程后端、Caddy HTTPS、本机 / 生产 Compose |

## 数据在哪里

- 本机数据库默认位于 `data/app.db`；可用 `APP_DATA_DIR` 配置绝对路径。
- `.env` 保存本机密钥；不要公开分享或上传。
- 数据、密钥、备份与依赖目录都已加入 Git 忽略规则。
- 关闭并重新启动程序不会清空回答。**删除 data 目录会丢失数据。**
