# 问卷云 · Wenjuan Cloud

一个以单问题回答为入口、在管理员控制台汇总生成词云的 Web 应用。

**当前状态：方案阶段。仓库已保存设计方案，应用代码尚未实现，暂无运行或部署入口。**

## 项目方案

完整方案见 [docs/PLAN.md](docs/PLAN.md)，包含功能范围、视觉设计、词云统计规则、技术架构、数据模型、API、部署方式与验收标准。

## 核心体验

- 用户打开网页只看到一个问题，匿名填写词语或短句并提交。
- 管理员登录独立控制台，查看所有有效回答的词云、词语排名及原文。
- 同一时间开放一道题，历史轮次单独保存和统计。
- 采用深空背景、冰青与紫罗兰微光、光环及粒子动效，呈现科技、奇幻、神秘的氛围。
- 词语权重按提及该词的有效回答条数统计，同条回答重复词只计一次。

## 拟采用技术

| 层级 | 技术 |
| --- | --- |
| 前端 | React + TypeScript + Vite |
| 视觉与词云 | CSS + Canvas、d3-cloud + SVG |
| 后端 | FastAPI |
| 中文分词 | jieba + 版本化规则 |
| 数据访问 | SQLAlchemy + Alembic |
| 持久化 | SQLite，首版独立单机部署 |

## 测试、部署与迁移

- 测试在本机完成，正式部署到 **2 核 CPU、2 GB 内存的 Linux 云服务器**。
- 本机最终验收与云端使用同一发布镜像，共用 Docker Compose，环境差异通过配置切换。
- 常驻一个 FastAPI 进程和 Caddy 入口；前端提前编译，词云及动画由用户浏览器绘制。
- SQLite 数据目录独立挂载；提供一致性备份、恢复、数据库升级和回滚流程。
- 默认只将题目与规则导入干净生产库，需要保留本机回答时使用完整数据迁移流程。
- 镜像在本机或 CI 构建，低配服务器只拉取或导入后运行；避免在云端占用内存打包。
- 迁移便利性通过恢复演练验收，2 核 2G 性能通过目标机器压测确认，尚未实测。

详细要求见 [完整方案](docs/PLAN.md)第 10 节；Docker 配置、程序和维护命令仍待开发。

## 实施顺序

1. 题目读取、回答持久化、多设备汇总与重复请求处理。
2. 管理员认证、轮次管理及原文查看。
3. 分词统计、规则调整、词云与排名。
4. 视觉动效、移动端适配及完整交互状态。
5. 发布镜像本机测试、2 核 2G 压测、迁移与备份恢复演练。

真实回答、数据库、备份和凭据不提交到此仓库。
