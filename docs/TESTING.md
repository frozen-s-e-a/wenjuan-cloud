# 测试与验收记录

验证结果：前端 TypeScript / Vite 构建通过；pytest **7 passed**。

## 自动化范围

运行环境：Linux / Python 3.12 / Node.js 24。测试使用隔离的临时数据库与合成文本，不读取真实回答。测试之前先构建前端，因为 HTTP 验收会检查根页面可正常返回。

```bash
python -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-dev.txt
npm ci --prefix frontend
npm run build --prefix frontend
.venv/bin/python -m pytest backend/tests -q
```

Windows 将 `.venv/bin/python` 换成 `.venv\Scripts\python.exe`。

覆盖：

- 公开回答入口、管理接口未登录拒绝、错误密码、CSRF、来源校验、请求体大小与未知接口。
- 两个匿名浏览器汇总、请求幂等、不同载荷冲突、每轮浏览器去重。
- 轮次切换后拒绝旧题提交，旧成功请求重试仍能返回相同结果。
- 提及次数计数、同义词与短语重算、贡献原文追溯、排除 / 恢复、版本冲突。
- 同一请求并发到达只保存一条；服务运行时拒绝离线维护。
- Backup API 一致性快照、数据库与外键检查、恢复后会话失效、重启读取。
- 仅题目与规则导出后导入全新数据库，不包含测试回答；非空库拒绝覆盖。

## 用户首次测试顺序

1. 启动后用示例题提交回答，后台应出现词云；刷新 / 重启后仍然保留。
2. 换另一浏览器或手机提交第二条，后台约一个 5 秒轮询周期后更新。
3. 点击词语看到对应原文；排除后计数下降，恢复后回升。
4. 新建轮次、开启；原先页面提交旧问题时应拒绝，历史统计保持独立。
5. 将 `AI=人工智能` 添加为同义词，并将“人工智能”添加为完整短语，保存后等待重算完成。
6. 验证未登录浏览器无法读取 `/api/admin/questions`。
7. 创建备份，停止服务后恢复，核对计数；最后再进行 Docker 与目标服务器验收。

10,000 条历史回答、每秒 5 次提交持续 10 分钟及每秒 20 次提交持续 30 秒仍是 v0.2 的待测目标，不应视为已通过的性能指标。若达到该规模，请在正式活动前完成实测。
